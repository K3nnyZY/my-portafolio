# Kenny Zhu Portfolio

A personal portfolio website built with Next.js, React, TypeScript, and Tailwind CSS.

This project is designed to showcase:

- Professional profile
- Featured projects
- Achievements
- Contact information

## Tech Stack 

- Next.js 16 (App Router)
- React 19
- TypeScript
- Tailwind CSS 4
- ESLint

## Project Structure

The project follows a clean and scalable structure:

```text
src/
  app/          # Routes, layouts, pages
  components/   # Reusable UI and page sections
  config/       # App/site configuration
  features/     # Business/domain logic (future)
  hooks/        # Reusable React hooks (future)
  lib/          # Utilities/helpers (future)
  types/        # Shared types (future)
```

## Getting Started

### 1. Install dependencies

```bash
npm install
```

### 2. Run the development server

```bash
npm run dev
```

Open `http://localhost:3000` in your browser.
